# ProxyServerAPI

`org.solarframework.mu:proxy-server-api` — what a local HTTPS reverse proxy serves, shared by its three implementations: [`NettyProxyServerImpl`](../NettyProxyServerImpl/README.md), [`SpringProxyServerImplV1`](../SpringProxyServerImplV1/README.md) and [`SpringProxyServerImplV2`](../SpringProxyServerImplV2/README.md). Each takes the same objects through its own `ProxyBuilder`.

- **`Domain`** / **`Subdomain`** (`BaseDomain`) — a host name, the IP it resolves to, and what it serves: a folder of files, or another server's URL to forward to. `new Domain(ip, name)` or `new Domain(ip, name, path)`; `addSubdomain(name)` / `addSubdomain(name, path)`.
- **`ProxyDomainsFile`** — every domain, stored in `config/proxy/domains.json`. It replaced the old `web_domain`/`web_subdomain` tables: the admin screen already saved them as a full reload, so a file loses nothing a query gave.
- **`RateLimitRule`** / **`ProxyRateLimitsFile`** — request limits, kept apart from domains because they control traffic rather than routing. A `"*"` host (`RateLimitRule.ALL_HOSTS`) limits every domain, a named host only that one.

- **`BaseDomain.fileFor(requestPath)`** — the file of a domain's folder a request asks for, the one check every implementation serves through: `index.html` for a slash, and empty for a path that climbs out, a folder, or **any segment that starts with a dot except `.well-known`** (RFC 8615). The dot rule is on every segment, not the file's name: a check of the name alone serves `.git/config`, which the three implementations' own copies all did until 16 Oct 2026.
- **`CallerHeaders`** — what a forwarded request tells the backend about its caller, written by every implementation that forwards: `X-Forwarded-For`/`X-Real-IP` the socket address, `X-Forwarded-Proto`/`X-Forwarded-Host` what the proxy saw, `X-ProxyGuard-Checked` `1` only after a contributed rule's check here, and `Forwarded`, `X-Forwarded-Prefix`, `X-Forwarded-Port` dropped. **Overwritten, never appended to**: a backend trusts `X-ProxyGuard-Checked: 1` from loopback (`IpUtils.alreadyCheckedByProxy`) and believes the *first* `X-Forwarded-For` entry (`IpUtils.callerAddress`) — behind a local proxy that is every request, so a caller's own would skip its allow list and limit or pass for another address.

With no path given, a domain's files live under `config/domain/`: the root domain (`mysite.com`) in `mysite.com/_`, a subdomain (`www.mysite.com`) in `mysite.com/_www`. A path starting with `http` is a server to forward to instead.
